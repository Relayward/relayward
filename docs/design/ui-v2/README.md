# Relayward UI v2 视觉方案

本目录用于评审 Relayward 控制中心的第二版视觉方向，不是前端实现或新增功能范围。

## 设计方向

- 使用固定分组侧栏组织资源、扩展、观测和系统功能，降低多页面切换成本。
- 使用紧凑的状态摘要、工具栏、表格和数据面板建立清晰的信息层级。
- 使用中性灰白作为基础、钢蓝色表达操作与选中状态，并让绿色只表达正常与成功。
- 参考 3x-ui 的运维面板布局与妙妙屋的数据概览表达，但不复制两者的业务结构和品牌元素。
- 登录页、管理端和公开订阅页使用同一套颜色、字号、状态与控件层级。

SVG 中的样例数据、统计图、搜索、筛选和导出控件用于表达布局和状态，不自动构成产品需求。实施时仍以已确认的 Relayward 功能范围为准。

## 基础视觉值

| 用途 | 值 |
| --- | --- |
| 页面背景 | `#F4F6F7` |
| 表面 | `#FFFFFF` |
| 主文字 | `#17231E` |
| 次级文字 | `#69767D` |
| 边框 | `#DDE3E6` |
| 主操作 | `#356F9F` |
| 主操作悬停 | `#2B5C86` |
| 主操作浅色背景 | `#EAF2F8` |
